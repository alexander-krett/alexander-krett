# Hi, I'm Alexander Krett 👋

**M.S. Computer Science @ Worcester Polytechnic Institute**  
Researching **AI safety, medical AI, LLM robustness, and representation engineering**.

My background spans **computer science, biochemistry, mathematics, and pharmaceutical R&D**. Before starting my M.S., I spent two years working in R&D at Novo Nordisk, where I also developed Python tools for scientific data processing and automation.
